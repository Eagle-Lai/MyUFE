### Animator 状态机结构（Player 和 Enemy 结构相同）

```
参数:
  Speed  (float)   — 0=静止, 1=行走, BlendTree 混合
  Attack (trigger) — 触发攻击动画
  Hit    (trigger) — 触发受击动画
  Death  (trigger) — 触发死亡动画

状态:
  Idle  ←默认状态, motion=IdleClip
  Walk  ←motion=BlendTree(Speed 0→Idle, 1→Walk)
  Attack ←motion=AttackClip
  Hit   ←motion=HitClip
  Death ←motion=DeathClip (无退出转换, 播完停留)

转换:
  Idle ↔ Walk     : Speed > 0.1 / Speed < 0.1
  Any  → Attack   : Attack trigger, 无 ExitTime
  Any  → Hit      : Hit trigger, 无 ExitTime
  Any  → Death    : Death trigger, 无 ExitTime
  Attack → Idle   : ExitTime 0.9 (播完90%)
  Attack → Walk   : ExitTime 0.9 + Speed > 0.1
  Hit → Idle      : ExitTime 0.8
  Hit → Walk      : ExitTime 0.8 + Speed > 0.1
  Death → (无退出) : 死亡后停留最后一帧
```
